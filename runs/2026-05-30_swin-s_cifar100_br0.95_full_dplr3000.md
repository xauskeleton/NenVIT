## Observations

- **−1.24% top-1 so với scope=skip** (87.43 vs 88.67) — binarize head.fc + downsample.reduction
  hại accuracy (đúng như cảnh báo "aggressive" của scope=full). Bù lại file nhỏ hơn 5.7 MB.
- Train chưa plateau (top-1 còn tăng 87.18→87.43 ở cuối), CE còn 0.029. Còn dư địa.
- DPLR loss ~1e-4, λ=3000 → đóng góp ~0.0001 → **không phải driver**. Giống run skip.
- Pareto rõ: **skip = accuracy cao + file to (7.6×); full = accuracy thấp hơn + file nhỏ (9.4×)**.
  Chọn theo ưu tiên accuracy hay compression.
