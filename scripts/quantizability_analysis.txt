## ACTIVATION QUANTIZATION POSITIONS (forward pass)

Per Swin block, activations to quantize (FIMA-Q does layer-wise A4):
  1. norm1.out        → input to attn.qkv      (post-LN, ~Gaussian, easy)
  2. qkv.out          → split into Q, K, V     (linear output, easy)
  3. Q @ K.T / sqrt(d) → input to softmax       (long tail, HARD)
  4. softmax.out      → input to V matmul       (in [0,1], HEAVY TAIL, HARDEST)
  5. attn @ V         → input to attn.proj      (post-softmax-weighted, MED)
  6. attn.proj.out    → residual add (KEEP FP)
  7. norm2.out        → input to mlp.fc1        (post-LN, ~Gaussian, easy)
  8. fc1.out          → input to GELU            (linear output, easy)
  9. GELU.out         → input to mlp.fc2         (post-GELU asymmetric, MED)
 10. fc2.out          → residual add (KEEP FP)

Critical: residual additions and skip connections stay FP.
